# Milestone 12 — Home Field Check cross-Herd child/session graph

## Design, production trace and ownership (recorded before implementation)

`CoreDataReadModelActor.fetchHomeFieldCheckRecords` supplies `LoadHomeUseCase.execute` and `HomeViewModel` with warning-session cards, the unresolved-finding count/single preview and `hasHistory`. It reads in one private context pinned to `.current`, validates complete selected-Herd session/finding/check UUID identity, probes corrupt selected-Herd findings, and validates the inverse children of *warning sessions*. Direct `CoreDataFieldCheckRepository.validateFieldCheckIdentity` checks both directions over the full Herd. Consequently, a selected-Herd animal check attached to a foreign-Herd session is invisible to Home when that session is not selected; likewise a foreign-Herd finding or check attached to a completed nonwarning selected-Herd session is invisible. For findings, Home already rejects selected-Herd findings pointing to foreign-Herd sessions, but not the reverse relationship outside warnings. Home can then publish apparently valid history/counts while the direct Field Check library correctly rejects the same persisted child graph.

Design: extend the existing Home corrupt-finding predicate to include foreign-Herd findings pointing into the selected Herd, and add a bounded, symmetric anomalous-animal-check query. In both cases test **physical Herd relationship ownership** of the child and its session and throw the existing typed `CoreDataReadModelError.invalidHerdOwnership`. Use `fetchLimit = 1` and no all-record child hydration. Keep the original corrupt-finding status probe, full-Herd UUID preflights, warning predicate/ordering, unresolved count, one-finding preview, history flag, and existing warning graph validator. No writes, repair, migration, UI, SwiftData, schema, new dependencies, or CI.

**This PR owns** the independent Home read boundary's complete selected-Herd Field Check child/session ownership preflight and its SQLite-backed cross-direction integration regression. **Existing owners:** M7 and M12 direct Field Check repository own legal writes and canonical complete-Herd graph invariant; M9 owns Home warning aggregation; #176/#177 own full-Herd session/child UUID preflights; #159 owns direct Field Check inverse graph; other M12 matrices own duplicate UUID and status validation. The change does not duplicate direct write/mutation tests.
