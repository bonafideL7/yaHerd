# Milestone 12 — Tag Color duplicate application-ID integrity matrix

## Design, observed gap and ownership

A selected-Herd Tag Color can be represented by more than one physical `CDTagColorDefinition` row with the same application UUID (the model does not impose a global UUID constraint because canonical built-ins may appear independently under distinct Herds). `CoreDataTagColorRepository.fetchColor(id:)` already fails closed through `CoreDataLookup.herdOwned`, whereas the complete-cohort `fetchManagedColors` path currently returns both physical rows. `fetchColors` collapses them into a dictionary by normalized name / built-in UUID and can silently hide a legitimate physical record or display an arbitrary definition. Write paths reusing this fetch may then mutate ambiguous records, and `reorder` uses the resulting list to materialize or assign order.

**Design:** Validate UUID uniqueness for the complete *selected-Herd* fetched cohort at the common `fetchManagedColors` boundary, before visibility filtering or Domain mapping, using the existing typed `CoreDataPersistenceError.duplicateApplicationID`. Do not mint identities, deduplicate, repair, choose one row, change model constraints, or inspect unrelated Herds. Retain direct `fetchColor(id:)` lookup behavior and the documented legitimate cross-Herd reuse of stable built-in IDs. The physical error must propagate before any write staging through all consumers of this common fetch.

This is an M12 end-state Core Data read/transaction integrity slice. M0/M11 own normal Tag Color CRUD, canonical built-in collisions/reference remapping, virtual defaults and historical lookup; earlier M12 owns multiple-default prioritization, not duplicate application-ID ownership. SQLite persistence foundation and selected-Herd contract suites remain the permanent owners of their independent primitives. No SwiftData, CloudKit, schema, recovery or navigation changes.

## Regression contract

Extend existing `CoreDataTagColorRepositoryContractTests` only. Seed two physical rows with one UUID under the first Herd, a distinct healthy control row, and the same UUID independently in a second Herd. Assert typed read failure, rejection of representative mutation categories with no persisted changes, exact selected-Herd identity, healthy second-Herd projection, and read-only SQLite reopen of the same physical state. No separate test harness.
