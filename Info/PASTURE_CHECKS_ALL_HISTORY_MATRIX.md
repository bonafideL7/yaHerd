# Pasture Checks All — full history projection (PR #198)

## Design, dependency boundaries, and ownership

- **Defect:** All previously applied a twelve-record limit to uncomplicated completed checks, and the Recent metric omitted completed checks with unresolved attention.
- **Implementation:** `FieldCheckAllSessionGroups` partitions every summary from `FieldCheckOverviewReading.fetchSessions()` into one display section: current Attention, current Open, current Completed, or Archived Pastures. Summary lifecycle counters include attention-bearing sessions, without counting archived-pasture sessions. Section membership and counts are derived on read; no stored state changes.
- **Owned by this PR:** All grouping/completeness/ordering, new Completed heading/count semantics, and `FieldCheckAllSessionGroupsTests`.
- **Existing contract ownership:** Core Data `FieldCheckRepositoryContract`/`CoreDataFieldCheckRepositoryContractTests` own session retrieval, finding/roster counts, completion/reopen and archived persistence; `AppNavigationStateTests` and the Phase 1 navigation matrix own Herd/Search/isolated routing; PR #196 and the Accessible Control Contrast matrix own card geometry/colors.
- **Out of scope:** Home/Dashboard count semantics, unrelated filter chips and other herds' records, edit workflows, Core Data schema, sync, recovery, migration. `FieldChecksViewModel.recentSessions` is an unused convenience projection and does not feed All.
- **Verification policy:** Repository instructions prohibit executing verification/tests unless explicitly requested. Static source/diff inspection is performed; new test assertions exist but have not been executed.

## Acceptance evidence and scope

- All includes each returned session exactly once even with more than twelve completed checks. Attention groups take precedence over lifecycle display groups for current-pasture sessions; archived-pasture entries remain in Archived Pastures regardless of other status.
- Open and Completed overview totals each include current-pasture Attention entries of the corresponding lifecycle state, while Archived remains separate. A completed check with an open finding counts toward both Attention and Completed.
- Completed rows are newest by completion time; archived rows retain open-first then newest-start ordering. All does not alter historical rows, timestamps or domain records.
- Production read paths traced: Herd/Search toolbar → `HerdTabRootView`; Home shortcut → `AppNavigationState`; isolated `IsolatedFieldCheckAreaView`; shared `FieldChecksView` → `FieldChecksViewModel.observe/load` → `FieldCheckOverviewReading.fetchSessions` → `CoreDataFieldCheckRepository.fetchSessions` (no fetch limit). `refreshable` uses the same load.
- `yaHerdTests/FieldCheckAllSessionGroupsTests.swift` protects 25 completed checks, attention and archive overlap, unique membership, and lifecycle count semantics. No builds/tests/verification commands were run by this change.
