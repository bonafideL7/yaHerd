# Milestone 9 Core Data Read-Model Behavioral Coverage Matrix

This matrix owns Milestone 9 of the SwiftData-to-Core Data replacement: Dashboard, Home supporting reads, Animal-list paging/query boundaries, and other performance-sensitive projections. Milestones 4–8 remain the owners of authoritative write-side persistence and feature-local read semantics. Milestone 10 owns runtime dependency cutover and post-commit publication wiring.

## Ownership and scope

- **This milestone owns:** Core Data implementations of the async read-model ports in `ReadModelRepository.swift`, query boundaries appropriate for real herd sizes, deterministic paging/sorting, selected-Herd isolation, fresh-read behavior, and read-only concurrency/cancellation behavior.
- **Existing permanent contracts reused:** `AnimalRepositoryReadModelContract`, `PastureDashboardReadModelContract`, `WorkingDashboardReadModelContract`, `HomeSupportingReadModelContract`, and cross-feature Animal revision/read-projection contracts.
- **Milestones 4–8 ownership reused:** authoritative Animal/Pasture/Field Check/Working persistence, snapshots, relationship validation, and write transactions.
- **Milestone 10 delegation:** production `AppDependencies` wiring to these Core Data readers and removal of SwiftData read-model actors from runtime composition.
- **Out of scope:** new SwiftData behavior, runtime hybrid fallback, presentation caches, CloudKit/share/sync behavior, and mutation logic.
- **Search/filter ownership:** M9 must move data-reduction work into Core Data where the production read port can express it. Presentation-only formatting/grouping remains Presentation-owned unless a persistence-neutral query input is added intentionally.
