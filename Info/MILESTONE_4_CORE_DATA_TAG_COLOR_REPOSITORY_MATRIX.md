## Ownership and scope

This PR owns the Core Data `TagColorRepository`, its Core Data contract runner, Core Data-only contract-test support needed to seed/inspect persisted reference graphs, and the tag-color Core Data behavioral matrix. The permanent persistence-neutral tag-color contract remains the invariant owner and is extended only when production tracing exposes a materially distinct missing lifecycle. App dependency cutover remains a later milestone. No new SwiftData implementation or dual-write path is introduced.
