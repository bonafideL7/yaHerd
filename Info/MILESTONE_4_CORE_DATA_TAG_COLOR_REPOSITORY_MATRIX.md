## Ownership and scope

This PR owns the Core Data `TagColorRepository`, its async Domain mutation capability, its Core Data contract runner, Core Data-only contract-test support needed to seed/inspect persisted reference graphs, and the tag-color Core Data behavioral matrix. Core Data writes use the Milestone 3 `CoreDataTransactionExecutor`; synchronous `performAndWait` is not used for Tag Color mutations. The existing synchronous Tag Color read capability remains temporarily unchanged because broader read-boundary/performance conversion is Milestone 9 ownership. `TagColorRepositoryContract` owns tag-color library behavior. `AnimalAggregateCrossFeatureRevisionContract` remains the sole owner of Animal revision invalidation caused by Tag Color remapping; its executable Core Data integration belongs with the Animal aggregate implementation in Milestone 5. App dependency cutover remains a later milestone. The existing synchronous SwiftData implementation remains untouched; Swift permits those synchronous witnesses to satisfy the async Domain mutation requirements. No new SwiftData implementation or dual-write path is introduced.
