# Phase 1 navigation discoverability — behavioral coverage matrix

> PR #188. Design inventory established before correcting review findings and reconciled to the implemented source paths. This is production path coverage, not an assertion that Xcode tests or runtime verification were executed.

## Decisions and invariants

- **One owner per state:** the navigation route owns the selected check-list filter. UI reads/writes the route; no extra view-local filter state can drift from scene restoration.
- YaHerd and Search have separate typed navigation paths. Changing a check-list filter updates the topmost matching route of the correct stack; it does not append another destination or change unrelated paths.
- The full-screen Field Check list uses its transient `WorkflowRouter.route`; its active session continuation remains governed by the existing restoration contract.
- The selected filter must be visible and accessible on iPhone widths and at larger Dynamic Type sizes. Retain horizontal scroll affordances.
- Status badges are pure view projections; a completed check may still have unresolved findings. No change to Domain/Repository data or derived counts.
- The Pastures toolbar presents a visible, labeled **Filter** menu bound to the existing `PastureListFilter`. A filled filter icon indicates an active filter; the menu offers every existing filter and **Clear Filter** when needed. Pasture Groups remains reachable only through the existing actions (`…`) menu. No persistence or migration changes.


> **PR #198 projection update:** the routes and chip bindings documented here are unchanged. The All list now uses Complete-history rather than limited Recent rows; `Info/PASTURE_CHECKS_ALL_HISTORY_MATRIX.md` owns its current section membership, metrics, reload and ordering contract. This matrix continues to own Phase 1 navigation.

## Verification ownership

- **This PR:** typed route filter selection, per-tab restoration, in-place projection selection, accessible selected-chip visibility, visible Pastures Filter menu, single Pasture Groups actions-menu route, labels and badges.
- **Existing permanent contracts:** Field Check repository status counts, finding resolution, and pasture group CRUD remain owned by their Domain/Core Data contracts; this PR changes their presentation only.
- **Explicitly out of scope:** database/persistence changes, search-mode redesign, Dashboard drill-down, full-screen workflow exit semantics.
- **Execution:** not run. Repository `AGENTS.md` requires no build, lint, tests, or CI verification unless explicitly requested. Source review and diff inspection are used here; Xcode/iOS behavior remains unverified until authorized.
