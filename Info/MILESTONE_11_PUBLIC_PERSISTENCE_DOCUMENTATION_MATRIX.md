## Review and verification scope

- Compare final README with `yaHerdApp.bootstrap`, `CoreDataAppPersistenceAssembly`, `CoreDataLegacyStorePreflight`, `RecoveryModeController`, `CoreDataPersistentContainer` and the M10 runtime cutover gate.
- Archived SwiftData sources under `LegacySwiftData/` preserve historical declarations, **not** users' stored rows and not an importer.
- A separate explicit release decision is required for devices containing existing SwiftData records. This PR does not solve that blocker.
- Per `AGENTS.md`, do not manually run builds, tests, lints, architecture verification or CI without an explicit user request; this is a static documentation review.
