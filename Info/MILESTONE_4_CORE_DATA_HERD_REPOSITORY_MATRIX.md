## Ownership and delegation

This PR owns the Core Data Herd repository, current-Herd scope abstraction, Herd mapping path, async Herd rename boundary, and the Core Data runner for `HerdRepositoryContract`.

Tag Color, Animal Status Reference, Pasture/Pasture Group, and Working Treatment Template repositories remain later Milestone 4 slices. Pasture deletion/movement transaction behavior remains Milestone 6. Application dependency cutover and the production current-Herd selection implementation remain Milestone 10.
