# Milestone 12 — Filtered Dashboard Animal complete-Herd UUID identity

## Design before production edits

`CoreDataReadModelActor.fetchDashboardRecords()` fetches and checks all selected-Herd `CDAnimal` IDs; the direct `CoreDataAnimalRepository.fetchAnimals()` and the independent Animal-list read actor also enforce complete-Herd application UUID identity. But `CoreDataReadModelActor.fetchDashboardAnimalRecords(kind:)` applies the active/working-pen/unassigned predicate **before** `validateUniqueApplicationIDs`. Two different selected-Herd physical Animals may share a UUID while only one matches a filter (for example, one active and one archived). The standalone Dashboard Animal list then displays the active Animal as healthy even though the direct Animal and full Dashboard reads reject the same store.

**Design:** In the filtered Dashboard read's existing private context, pin `.current` query generation; resolve the selected Herd, run existing `validateAnimalApplicationIDs(herd:herdID:in:)` (an ID-only dictionary-result check over **all** physical selected-Herd Animals), then execute the existing filtered fetch, relationship validation, deterministic ordering and Domain mapping unchanged. Throw the established `CoreDataPersistenceError.duplicateApplicationID` for any selected-Herd collision, including rows excluded from the current filter; reject without repair or partial results. This shares the existing validator and adds no schema, abstraction, migration, SwiftData path, mutation, sync or UI change.

**Callers and scope:** `LoadDashboardAnimalListUseCase.execute` calls `DashboardQueryReading.fetchDashboardAnimalRecords(kind:)`; `DashboardAnimalListViewModel.load` renders the standalone Active/Working Pen/Unassigned Dashboard lists. `LoadDashboardUseCase` and `LoadHomeUseCase` call the separate `fetchDashboardRecords()` path, which already checks all selected-Herd Animals. `CoreDataAnimalRepository.fetchAnimals()` and the M9 Animal-list readers own direct/Animal-list identity behavior. This PR owns only the independent filtered Dashboard Animal read, including one-generation preflight consistency; M9 owns filters, order, projection, and the async actor boundary. No production mutation pathway changes.
