# Animal list sorting control — behavior matrix

## Finding and design
Both the YaHerd/Search tab bottom accessory and the in-list floating toolbar reuse `AnimalSortMenuPicker`. The current picker maps Tag Descending to Tag Ascending (and Birth Date Oldest to Newest) in its selection getter, then maps a user choice back to the default ascending/newest value. Consequently the control reports a different active choice from the actual `AnimalSortOrder`, and choosing the apparent active item cannot reliably change direction. The independent top-bar reverse button does not repair the misleading menu state.

**Fix:** Make each of the eight persisted `AnimalSortOrder` values directly selectable in the shared picker (with full direction labels) and bind `Picker` to the actual `sortOrder`, not a normalized proxy. Keep the existing top-bar reverse action, `HerdRouter.sortOrder`, derivation actor, filters, and list presentation unchanged. This is a UI-bound state representation defect; existing sort comparators and model reload flow are outside the change.
