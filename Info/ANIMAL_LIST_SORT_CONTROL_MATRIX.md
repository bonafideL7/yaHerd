# Animal list sorting control — behavior matrix

## Diagnosis and design

**Observed by user:** Tapping **Sort** does nothing; the previous fix (PR #191's first two commits) only corrected sort options and never fixed menu presentation.

**Affected production caller graph:**
- `MainTabView` attaches `HerdTabBottomAccessory` via `.tabViewBottomAccessory`. This view chooses between `AnimalListTabAccessoryControls` and `AnimalListInlineTabAccessoryControls` as iOS 26 expands/collapses the tab bar.
- Both variants currently put `AnimalSortMenuPicker` inside `Menu`. A working Picker binding does not help when the menu itself is not presented.
- Production callers of `AnimalListView` are routed through `HerdTabRootView` with `usesShellBottomAccessory: true`, so `AnimalListFloatingControlBar` is not constructed in normal app navigation. The only `AnimalListView()` using the default standalone controls is under `#Preview`.
- The production sort owner is `AppNavigationState.herdRouter.sortOrder` for YaHerd and Search. The actual list recomputation is triggered by `AnimalListView.onChange(of: sortOrderValue)` and calculated in `AnimalListViewModel` / `AnimalListDerivationActor`.

**Fix approach:** Use tappable **Button** controls instead of nested accessory `Menu` → `Picker`:
1. The main tab accessory Sort button sets transient `HerdRouter.showingSort`. The existing `AppNavigationPresentationModifier` owns the native sort confirmation dialog **outside** the tab-bar accessory hierarchy, and writes the exact `HerdRouter.sortOrder` enum case. This reuses the established modal presentation boundary and respects the architecture check that forbids any `@State` in `MainTabView`.
2. Leave `AnimalListFloatingControlBar`, its preview-only `AnimalSortMenuPicker`, and `AnimalListView`'s standalone presentation unchanged. **Production callers: None: preview-only** for the standalone floating-bar Sort UI; it is not an additional production workflow or contract owner.
3. The app-owned confirmation dialog enumerates `AnimalSortOrder.allCases` to offer eight distinct choices, independent of the six-category preview Picker; preserve the top-bar reverse button, state restoration, search/filter, list derivation and grouped sections.
4. Do not change list repositories, Core Data or business sorting comparators. Runtime symptom is a missing menu presentation, not evidence that the comparator fails.
