# Milestone 8 Core Data Working Persistence Matrix

This matrix is the living behavioral inventory for Milestone 8 of the Core Data replacement plan. It is created before production implementation, as required by `AGENTS.md`, and must be reconciled as the Working call graph and implementation evolve.

## Ownership and scope

- **This milestone owns:** Core Data Working session, queue-item, treatment-record, generated health/pregnancy, tag-replacement integration, Working lifecycle transactions, Working historical snapshots, Herd scoping/identity, rollback/recovery, and the Core Data runner for the permanent Working contract family.
- **Existing permanent contract owners reused:** `WorkingRepositoryContract` and its Lifecycle, WorkData, PlansTagsAndTemplates, and AtomicityRollback extensions; `AnimalAggregateCrossFeatureRevisionContract` for Working-driven Animal revision rotation; `HealthRepositoryContract` for non-Working health/pregnancy behavior.
- **Milestone 4 ownership reused:** `CoreDataWorkingTreatmentTemplateRepository` remains the existing Core Data treatment-template implementation. M8 may adapt its Domain mutation surface only as required by the shared async Working mutation boundary; template semantics are not reimplemented.
- **Milestone 6 dependency:** reusable Core Data animal movement semantics and Pasture-deletion coordination.
- **Milestone 9 delegation:** optimized Working dashboard/Home/read-heavy projections and broader query performance.
- **Milestone 10 delegation:** runtime `AppDependencies` cutover and post-commit mutation-publication wiring around the Core Data Working implementation.
- **Out of scope:** new SwiftData behavior, SwiftData contract runners, migration/fallback architecture, CloudKit/share/sync behavior, and persisted presentation caches.
