# Milestone 12 — direct Animal parent-option tie ordering

## Finding and design before production edits

`CoreDataAnimalRepository.fetchParentOptions(excluding:)` returns selected-Herd, non-archived Animal parent options, mapped to stable `AnimalParentOption` IDs. Its in-memory sort uses `localizedStandardCompare` on `displayName` alone. Distinct legitimate animals share display names, especially untagged females and males, so those options have no defined relative order in direct reads or new SQLite contexts. The separately implemented `CoreDataReadModelActor.fetchParentOptions(excluding:)` already sorts by the same display name **and** UUID, and is the production asynchronous reader consumed by `AnimalParentPickerViewModel`.

Design: append persisted application UUID ascending **only for equal display names** to the direct repository's comparator, matching the existing asynchronous ordering exactly. Keep the complete selected-Herd, non-archived cohort, exclusion filter, prior parent graph validation, display-name precedence, and existing `AnimalParentOption` projection. The direct `AnimalRepository` contract is exposed through App coordination wrappers; do not claim that the current picker calls the synchronous reader. No schema, write, migration, recovery, UI, SwiftData, or new abstraction.

## Contract owners and exclusions

- **This PR:** stable equal-display-name ordering in the synchronous direct parent-option reader, including parity with the existing asynchronous reader, tested across independent read-only SQLite reopen.
- **M5:** Animal create/update/parent relationships, Herd scope, stable UUIDs, archive behavior and transaction contracts.
- **M9/M10:** the asynchronous pinned-generation parent-option query and `AnimalParentPickerViewModel` load/filter/display behavior.
- **Previous M12 Animal read graph:** foreign-Herd/reverse owner checks on both direct and async paths; this change preserves that preflight.
- **Excluded:** any parent mutation, list pagination, archived eligibility change, alternative sort collation, or duplicate parent-picker test harness.
