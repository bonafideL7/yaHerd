# Milestone 11 — Legacy Entry-Point Removal Matrix

Milestone 11 removes obsolete SwiftData implementation **after** the single-stack Core Data runtime gate. This first focused PR deletes four strictly unreferenced SwiftData entry points only. It does not delete persisted user files, schema/models or legacy test dependencies.

## Scope and data-preservation boundary

- **Removal:** `yaHerd/App/Persistence/SwiftDataPersistenceAssembly.swift`; `yaHerd/App/AppSampleDataSeeder.swift`; `yaHerd/Data/Repositories/SwiftDataReadModelActor.swift`; `yaHerd/Data/Repositories/SwiftDataDashboardRepository.swift`.
- **Retained:** `CoreDataAppPersistenceAssembly`, Core Data recovery/export and `CoreDataLegacyStorePreflight`; all legacy schema/model records and the SwiftData-backed test fixture, which are not safe to drop before their full dependency inventory.
- **Legacy stores:** `yaHerdStore.store`, `yaHerdStore.sqlite`, `default.store` and SQLite journal sidecars are recognized on first open and remain read-only/exportable. **There is no implemented legacy-to-Core Data data migration.** Shipping a replacement store to current users requires a separate data-preserving release decision.
- **Code-build ownership:** the Xcode project uses file-system-synchronized `yaHerd` and `yaHerdTests` groups. Removing Swift files from the `yaHerd` tree excludes them from the target automatically; no stale file-specific build phase references are present.
- **Contract ownership:** M10 owns active Core Data graph cutover; M9 owns Core Data readers; M4–M8 own writes; this PR owns only unused entry-point deletion.

## Further M11 inventory (not removed in this PR)

Remaining legacy domains include `yaHerd/Data/Models`, `yaHerd/Data/Persistence/Schema`, `ModelContainerFactory`, `DefaultHerdBootstrapper`, legacy SwiftData write repositories, seeding source and `yaHerdTests/TestSupport.swift`. These still form an interdependent model/test-source graph and require follow-on source/contract tracing. In particular, `SampleLargeDataService.swift` contains a generated full-herd example seed: do not discard that source blindly when deleting the obsolete runtime.

No test, build, lint or manual CI execution is authorized for this PR under `AGENTS.md`; review is by static caller searches and diff inspection.
