# Milestone 0 Application Identity Behavioral Coverage Matrix

This matrix is the behavioral inventory for PR #87. It describes the permanent persistence-neutral application-identity contract that must survive the Core Data cutover. This PR owns first-save/fresh-reload UUID preservation for the complete durable-entity inventory plus duplicate-UUID integrity inside one repository identity scope. Existing feature contracts own later feature edits, lifecycle behavior, relationships, and Domain-visible projections they actually expose. Executable persistence verification is deferred to the future Core Data contract runner per `AGENTS.md`.

## Ownership notes

- This PR owns generic duplicate application-UUID integrity inside one repository identity/ownership scope.
- The generic identity contract does not impose cross-Herd global uniqueness. Current Tag Color behavior intentionally uses the same stable built-in application IDs in independently scoped Herd libraries; that behavior remains owned by `TagColorRepositoryContract`.
- This PR owns first durable save/fresh reload for every independently persisted entity kind. Feature repository contracts own subsequent feature-visible UUID lifecycle, relationship resolution, history, deletion/nullification, Herd scoping, and read-projection behavior.
- `HerdRepositoryContract` remains the owner of current-Herd selection and Herd-root multiplicity behavior.
- Core Data model/foundation work remains the owner of physical attribute/constraint/index structure and framework-specific error translation. A physical uniqueness constraint must not be stronger than the permanent feature contracts.
- `MutationBoundaryContract` remains the owner of production mutation publication timing; the target-only identity seeding control does not publish application mutation events.
