# Milestone 0 Application Identity Behavioral Coverage Matrix

This matrix is the behavioral inventory for PR #87. It describes the permanent persistence-neutral application-identity contract that must survive the Core Data cutover. Ordinary feature create/read/update/reload identity behavior remains owned by the feature repository contracts; this PR owns the cross-cutting duplicate-UUID integrity invariant that those public APIs cannot directly inject. Executable duplicate persistence verification is deferred to the future Core Data contract runner per `AGENTS.md`.

## Ownership notes

- This PR owns only generic duplicate application-UUID integrity, including the distinct cross-Herd duplicate path.
- Feature repository contracts remain the single owners of normal UUID lifecycle, relationship resolution, history, deletion/nullification, and read-projection behavior.
- `HerdRepositoryContract` remains the owner of current-Herd selection and Herd-root multiplicity behavior.
- Core Data model/foundation work remains the owner of physical attribute/constraint/index structure and framework-specific error translation.
- `MutationBoundaryContract` remains the owner of production mutation publication timing; the target-only identity seeding control does not publish application mutation events.
