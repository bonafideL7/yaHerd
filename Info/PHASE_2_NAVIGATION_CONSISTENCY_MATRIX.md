# Phase 2 navigation consistency — behavioral coverage matrix

Design established before production edits. This matrix owns only navigation/presentation transitions. Phase 1 check-list filter contracts remain owned by merged PR #188; Core Data, checks and work repositories remain unchanged. Tests are updated as normal source but never executed without explicit verification authorization under AGENTS.md.

## Invariants

- YaHerd Animals/Pastures mode is owned by `HerdRouter.mode`; Search always displays Animals without writing that mode; the YaHerd Animals/Pastures toggle is hidden in Search because Search has no mode switch. Existing search criteria remain shared by design; changing search filter ownership is outside this PR.
- A full-screen flow must retain its underlying selected tab. Close removes the flow; Back exists only when session opened from a list inside that flow, and returns to the same list/filter. If a session becomes unavailable, list-launched sessions return to their saved list, while directly launched sessions close back to the presenting tab.
- Live revalidation uses record existence rather than active status for the presented check/working-session detail; durable restoration still admits only active sessions. The Home Field Work filtered shortcuts must not silently switch to YaHerd. Direct Home session shortcuts keep their origin. Home animal/pasture record shortcuts intentionally continue to open their canonical lists on YaHerd as an out-of-scope records navigation policy.
- A newly created working session should use the same isolated work area as all other session launches.
- Successful deletion from WorkingSessionDetailView must never dismiss an entire isolated list workflow when the deleted detail was opened from that list. Pushed details retain standard dismissal. Callback identity checks protect against revalidation changing the route first.
- Scene restoration persists active existing sessions only, never transient workflow list/back state. Validation failures do not redirect users to unrelated tabs.
